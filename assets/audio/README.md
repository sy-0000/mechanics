# 使用者音檔(選用)

放進這個資料夾、檔名與下表相同的音檔(`.mp3`、`.ogg`、`.wav`、`.m4a`),就會取代對應的合成音效;沒有的音效照常用 Web Audio 即時合成。

| 檔名 | 用在 |
| --- | --- |
| `button` | 碰按鈕、選單 |
| `grab` / `release` | 抓取 / 放開 |
| `detent` | 旋鈕每格「喀」 |
| `limit` | 旋鈕卡住提示音、跟隨模式下不能切換 |
| `tooth` | 齒輪過齒 |
| `jam` | 機構卡住 |
| `deadCenter` | 死點的低沉悶響 |
| `ignite` | 引擎點火「轟」 |
| `knock` | 太早點火的敲擊聲 |
| `spark` | 火星塞「答」 |
| `lock` | 肘節越過中心「喀」 |
| `crush` | 壓扁鐵罐的金屬擠壓聲 |
| `stamp` | 完成任務蓋章 |
| `slip` | 摩擦輪打滑 |
| `snap` | 零件卡進定位 |
| `whoosh` | 過場動畫 |

馬達運轉聲是連續合成音,不能用音檔取代。
