# 場景決策紀錄

提示詞沒有寫到、或需要取捨的細節,在此記錄理由。

## 技術與檔案
- **新增物件(第二版)**:桌面的捲尺、三角板、美工刀、零件盤(螺絲 / 螺帽 / 華司);其他兩張桌上的圖紙、鋼尺、砂紙磨塊、木塊、白膠、捲尺、零件盤、三角板、美工刀;前牆右側的鋼製材料櫃(櫃頂兩個無字紙箱);右牆洞洞板與前牆之間的木製吊櫃與 4 × 5 小零件抽屜盒。都放在教具掛載區外,不擋學生伸手。
- **工具鏈**:Vite 5 + three r170(npm 本地安裝,不從 CDN 載入任何資源)。`npm run dev` 開發,`npm run build` 輸出 `dist/`(含 `index.html` 預覽頁與 `vr.html` VR 測試頁)。
- **字型**:採用手寫風的 LXGW WenKai TC(霞鶩文楷,OFL),子集為 Big5 常用字 + 符號(約 5400 字,1.6 MB woff2),見 `src/assets/fonts/README.md`。缺字時退回系統中文字型。
- **每個物件獨立檔案**:工具在 `tools/`、作品在 `works/`;散落物的鉛筆、橡皮擦、鋼尺、F/C 夾也放在 `tools/`(洞洞板與桌面共用鋼尺模型)。另增 `safetyTape.js`、`debugStats.js`、`environment.js`、`postfx.js`(取代 `dof.js`)、`partsTray.js`、`storageCabinet.js`、`wallCabinet.js`、`util/`(建模工具、合併器、工具實例化)。
- **執行期合併(staticBatcher)**:物件各自建模,載入後依材質屬性合併;顏色烘進頂點色,所以不同顏色可共用 draw call。動畫物件與掛載點(夾鉗、鐵罐、吊扇轉子)在各自群組內合併,仍保持獨立 Object3D。
- **遠景烘焙**:遠景物件把柔和環境遮蔽(地面附近、天花板角落略暗、朝下面略暗)烘進頂點色,VR 沒有 SSAO 時仍有接觸陰影感。

## 渲染風格:寫實 PBR(第二版)
第一版是三渲二卡通風格;第二版依需求改為寫實 PBR,格局、物件位置與黑板內容都不變。
- **材質**:全部改為 `MeshStandardMaterial`(`src/materials/standard.js` 的 `std()`),移除所有反向外殼描邊與 `MeshToonMaterial`(`outline.js`、`toon.js` 已刪除)。
- **PBR 貼圖**:全部程序產生(`src/materials/pbrTextures.js`),不從網路下載。每組三張 1024 貼圖:
  `map`(sRGB 反照率)、`normalMap`(由高度圖 Sobel 計算)、`ORM`(R=凹陷 AO、G=粗糙度、B=金屬度,同一張貼圖同時給 aoMap / roughnessMap / metalnessMap,省記憶體與取樣)。
  - 木材(一般木紋 / 集成材 / 節眼實木):年輪、導管細孔、節眼、使用刮痕;左右無縫重複。
  - 磨石子地板:石粒、細微裂痕(含分岔)、大片髒污、鞋印擦痕;打磨面粗糙度約 0.4。
  - 牆面乳膠漆:細微橘皮紋與淡斑,霧面。
  - 金屬:拉絲(工具鋼、鋁)、烤漆(機台、材料櫃,掉漆處露出金屬)、鑄鐵(顆粒);都有刮痕與磨亮斑。金屬的 `envMapIntensity` 為 2.4,反光明顯。
  - 布料:織紋法線。黑板:石板細紋。
- **頂點色合併**:材質 color 仍烘進頂點色,依貼圖組與粗糙度/金屬度合併 draw call(`util/staticBatcher.js`)。
- **語意色檢查**:`node scripts/check-palette.mjs`,目前全數通過。限制:窗外樹冠與草地不能接近輸出件綠 #75A17B,所以只能用偏灰的橄欖色,看起來比真實的樹灰。

## 光照與渲染(第二版)
- **主光**:暖色平行光(#FFE2BC,3.4)從左窗斜射,唯一的陰影光源,`PCFSoftShadowMap`。陰影範圍涵蓋整間教室(±5.6 × ±4.6 m),牆與窗框都會投影,所以地板上的窗格是真實陰影。陰影圖 2048(電腦)/1024(VR)。
- **環境光** 0.25(烘焙模式 0.45)。
- **補光**:三盞 2700K(#FFA757)PointLight,強度 1.6、範圍 7.5 m,不投影;位置 (−1.2, 2.55, −1.4)、(1.5, 2.55, 0.3)、(−0.2, 2.55, 2.4)。
- **環境貼圖**:沒有外部 HDRI,改以程序建一個「教室 HDRI」(奶油色房間、HDR 亮度 9 倍的窗面、天花燈),用 PMREM 預過濾,`scene.environmentIntensity = 0.55`。擷取點在眼睛高度(在地面擷取會讓下半球全黑、金屬變黑)。`options.hdriUrl` 可改用真的本地 `.hdr`。
- **色調**:`ACESFilmicToneMapping`、sRGB 輸出、曝光 0.95(`setExposure()` 可調)。
- **霧**:寫實版只保留很淡的大氣霧(7–30 m,色 #CFC8BA),避免室內泛白。
- **後製(只在電腦)**:Render → GTAO(半徑 0.35 m)→ 景深(只在工作桌近景)→ 輕微 UnrealBloom(強度 0.28,門檻 1.4 線性值:只有燈具自發光 3.2 與強烈高光會發亮)→ OutputPass。
- 第一版的「假光束面片」與「投影光斑貼片」已移除,改由真實陰影形成窗光;光中的微塵保留。

## 效能檔位(第二版)
| 檔位 | 用途 | 後製 | 陰影 | 補光 | draw calls | 三角形 |
| --- | --- | --- | --- | --- | --- | --- |
| `high` | 電腦 | GTAO + Bloom + 景深 | 2048 即時 | 3 盞 | ≈630* | ≈1.1M* |
| `vr` | Quest 3 預設 | 無 | 1024 即時 | 3 盞 | ≈199 | ≈377k |
| `vr-baked` | Quest 3 掉幀時 | 無 | 1024,算一次後凍結 | 關閉 | ≈108 | ≈183k |

\* high 的數字包含 GTAO 與景深各自重畫一次場景。
- **烘焙光照**:`vr-baked` 把主光陰影圖只算一次後凍結(`shadowMap.autoUpdate = false`),等於把窗光陰影烘焙成一張光照貼圖,每幀沒有陰影成本;太陽停止漂移,以免陰影錯位;關閉補光燈並提高環境光與環境貼圖強度;解析度倍率 0.85、注視點渲染全開。遠景環境遮蔽一律烘焙在頂點色裡。
- **自動降級**:VR 中連續約 3 秒(216 幀)平均低於 66 fps,就自動切到 `vr-baked`(`options.autoFallback`,預設開)。
- **限制**:凍結期間,教具的陰影不會即時更新。教具專案可以在狀態改變後呼叫 `classroom.refreshShadows()` 重算一次。
- 以上數字是在沒有 GPU 的軟體繪製環境量測的,FPS 沒有參考價值;**Quest 3 實機數據待確認**。

## 窗外
- 窗外物件 `fog=false`,改把大氣霧化直接烘進顏色(依距離混向 #FEFDF5),否則 10 m 全霧會讓操場一片白、地平線消失。
- 校舍擺在操場兩側與遠端,中央保留視野,能看到跑道與山稜線。走廊欄杆下方實心矮牆降為 0.3 m,欄杆加高,以免擋住跑道。

## 配置調整(與提示詞的「約」值差異)
- **展示櫃** 改為 x 0.35–2.15(提示詞約 0.4–2.6),讓出後牆右側角落的木門(中心 x 2.7、寬 0.9)。
- **角材** 放在 x≈−0.55,**垃圾桶** 移到 x −0.12,因為 2.44 m 長的密集板向右延伸到 x≈−0.69。
- **木料架** x −3.05…−0.9;密集板深 1.22 m 超過層架深度,向前凸出(真實木料架常見)。
- **學生的圓凳** 塞在桌下 (0.38, −0.5),不與站在原點的學生重疊。
- **圍裙掛勾** z 0.62(提示詞約 0.4),避免與洞洞板(到 z 0.2)及最右邊圍裙重疊。
- **熱熔膠槍** 掛在剪刀/尖嘴鉗下方,避免擋住線材橫桿。

## 視角
- **電腦工作桌近景**:鏡頭 (0, 1.58, 0.62) 看向 (0, 0.9, −0.75),可小範圍環繞(方位 ±0.55 rad、俯仰 ±0.28 rad、距離 0.55–1.35 倍)。景深用 three 的 BokehPass(`postfx.js`),焦點每幀設為鏡頭到掛載區中心的距離;切換時景深強度與霧同步淡入淡出。
- **黑板視角**:鏡頭 (0, 1.6, −1.15) 正對黑板,景深關閉,霧最淡。
- 平移路徑為「起點 → 抬高 25 cm、側移 15 cm 的中點 → 終點」的 centripetal Catmull-Rom 曲線,注視點線性插值,2.5 秒 ease-in-out(三次)。
- **VR 傳送**:偏移 XR 參考空間(`getOffsetReferenceSpace`),公式 O = H·T⁻¹(H 為目前頭部在基準空間的水平位置與偏航,T 為目標站位),只取偏航;淡出/淡入各 0.25 秒,淡出色為 #FEFDF5。進入 VR 的第一幀自動把學生頭部對齊原點、面向黑板。

## 選單
- 小黑板風格的場景內面板,畫在 canvas 上(粉筆字,屬「黑板粉筆字」例外)。電腦版掛在鏡頭左下;VR 版出現在左手(手把或手部)上方、面向頭部。
- 開啟:鍵盤 Y;Quest 左手把 `gamepad.buttons[5]`(xr-standard 的 Y,**待實機確認**);手勢:左手掌心朝上(掌心法線 y>0.65)時掌上出現小圓鈕,右手食指尖 2.5 cm 內觸碰即開啟。
- 選取:滑鼠點擊、右手把射線 + 扳機、或右手食指尖戳面板。
- 手把模型為自製膠囊(不從 CDN 下載 controller profile);手部模型用 three 的 `spheres` 程序模型。
- 進入 VR 的按鈕只有圖示(取代會顯示「ENTER VR」文字的 VRButton)。

## 黑板 API 細節
- `setZone` 動畫:有舊內容時先板擦掃過 0.32 秒(留下逐次淡化的擦拭痕),再逐行由左而右寫出 0.48 秒,共 0.8 秒;回傳 Promise。
- `updateValues` 累積數值,在每幀更新時以「每秒最多一次」套用,只重繪該分區 canvas,不重播動畫;粉筆顆粒以內容雜湊為種子,重繪不閃爍。
- 標記:`x^{2}`、`F_{in}`、`\frac{a}{b}`(可巢狀)、`{key}`。數字自動格式化(≥100 取整、≥10 一位小數、其餘兩位)。
- 字高:中區標題 9.5 cm、公式 8 cm、即時數值 7.5 cm;左區 5.8 cm(固定定義,自動換行);右區 6.5 cm。內容過長時自動縮小(最低 75%)。
- 另提供便利函式 `board.setAdvanced(on, content)`:開啟寫右區、關閉擦右區。
