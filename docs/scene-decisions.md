# 場景決策紀錄

提示詞沒有寫到、或需要取捨的細節,在此記錄理由。

## 技術與檔案
- **工具鏈**:Vite 5 + three r170(npm 本地安裝,不從 CDN 載入任何資源)。`npm run dev` 開發,`npm run build` 輸出 `dist/`(含 `index.html` 預覽頁與 `vr.html` VR 測試頁)。
- **字型**:採用手寫風的 LXGW WenKai TC(霞鶩文楷,OFL),子集為 Big5 常用字 + 符號(約 5400 字,1.6 MB woff2),見 `src/assets/fonts/README.md`。缺字時退回系統中文字型。
- **每個物件獨立檔案**:工具在 `tools/`、作品在 `works/`;散落物的鉛筆、橡皮擦、鋼尺、F/C 夾也放在 `tools/`(洞洞板與桌面共用鋼尺模型)。另增 `safetyTape.js`、`debugStats.js`、`util/`(建模工具、合併器、工具實例化)。
- **執行期合併(staticBatcher)**:物件各自建模,載入後依「貼圖 + 面向」合併;卡通材質的顏色烘進頂點色,所以不同顏色可共用 draw call;所有描邊外殼合併成單一 Mesh。動畫物件與掛載點(夾鉗、鐵罐、吊扇轉子)在各自群組內合併,仍保持獨立 Object3D。
- **遠景烘焙**:遠景物件把柔和環境遮蔽(地面附近、天花板角落略暗、朝下面略暗)烘進頂點色,且不投射/接收即時陰影;近景(工作桌一帶)保留即時陰影。

## 外觀
- **卡通明暗**:`MeshToonMaterial` 三階梯度(最暗 60%),避免死黑。
- **描邊色**:深棕 `#33261D`。它與保留色「機架深棕 #5A3A28」ΔE≈16,但規格明訂深棕描邊,且只是 1–3 px 線條,不構成物件色塊;已在 `scripts/check-palette.mjs` 中列為例外。
- **語意色檢查**:`node scripts/check-palette.mjs` 會掃描所有原始碼顏色,ΔE<20 即報錯;目前全數通過。木色一律壓低飽和(櫸木 `#E4CFAB`),握把用灰黑/奶油/透明感奶油,機台用暖灰與奶油白,窗外樹冠與草地為灰橄欖色。
- **銅線**:`#A58C80`(灰粉褐)取代銅色,避免接近銅橘。
- **安全標示**:機台地面區用奶油白膠帶與前角斜紋(圖示),沒有文字。
- **地板「柔和反光」**:卡通材質沒有鏡面反射;以窗光光斑(加法混色)與磨石子顆粒呈現,不做反射。

## 光照
- 窗光是唯一投影的平行光,陰影相機只框住工作桌 ±1.4 m;陰影圖 2048(high)/1024(vr)。
- **窗框光影**:因為陰影只框住工作桌,地面的窗框光影改用投影光斑貼片(依太陽方向從三扇窗投影到地面),並極緩慢移動(正弦漂移,週期約 26 分鐘);工作桌上則是真的即時陰影。
- **光束**:每扇窗兩片極淡的加法混色光片(無後處理),微塵 260 顆(vr 140 顆)沿光束漂浮。
- 展示櫃「櫃內暖光」不用即時光源,改以暖色背板 + 層板下的發光燈條呈現,節省效能。

## 窗外
- 窗外物件 `fog=false`,改把大氣霧化直接烘進顏色(依距離混向 #FEFDF5),否則 10 m 全霧會讓操場一片白、地平線消失。
- 校舍擺在操場兩側與遠端,中央保留視野,能看到跑道與山稜線。走廊欄杆下方實心矮牆降為 0.3 m,欄杆加高,以免擋住跑道。

## 配置調整(與提示詞的「約」值差異)
- **展示櫃** 改為 x 0.35–2.15(提示詞約 0.4–2.6),讓出後牆右側角落的木門(中心 x 2.7、寬 0.9)。
- **角材** 放在 x≈−0.55,**垃圾桶** 移到 x −0.12,因為 2.44 m 長的密集板向右延伸到 x≈−0.69。
- **木料架** x −3.05…−0.9;密集板深 1.22 m 超過層架深度,向前凸出(真實木料架常見)。
- **學生的圓凳** 塞在桌下 (0.38, −0.5),不與站在原點的學生重疊。
- **圍裙掛勾** z 0.62(提示詞約 0.4),避免與洞洞板(到 z 0.2)及最右邊圍裙重疊。
- **熱熔膠槍** 掛在剪刀/尖嘴鉗下方,避免擋住線材橫桿。

## 視角
- **電腦工作桌近景**:鏡頭 (0, 1.58, 0.62) 看向 (0, 0.9, −0.75),可小範圍環繞(方位 ±0.55 rad、俯仰 ±0.28 rad、距離 0.55–1.35 倍)。景深用 three 的 BokehPass,焦點每幀設為鏡頭到掛載區中心的距離;切換時景深強度與霧同步淡入淡出。
- **黑板視角**:鏡頭 (0, 1.6, −1.15) 正對黑板,景深關閉,霧 5.5–14 m。
- 平移路徑為「起點 → 抬高 25 cm、側移 15 cm 的中點 → 終點」的 centripetal Catmull-Rom 曲線,注視點線性插值,2.5 秒 ease-in-out(三次)。
- **VR 傳送**:偏移 XR 參考空間(`getOffsetReferenceSpace`),公式 O = H·T⁻¹(H 為目前頭部在基準空間的水平位置與偏航,T 為目標站位),只取偏航;淡出/淡入各 0.25 秒,淡出色為 #FEFDF5。進入 VR 的第一幀自動把學生頭部對齊原點、面向黑板。

## 選單
- 小黑板風格的場景內面板,畫在 canvas 上(粉筆字,屬「黑板粉筆字」例外)。電腦版掛在鏡頭左下;VR 版出現在左手(手把或手部)上方、面向頭部。
- 開啟:鍵盤 Y;Quest 左手把 `gamepad.buttons[5]`(xr-standard 的 Y,**待實機確認**);手勢:左手掌心朝上(掌心法線 y>0.65)時掌上出現小圓鈕,右手食指尖 2.5 cm 內觸碰即開啟。
- 選取:滑鼠點擊、右手把射線 + 扳機、或右手食指尖戳面板。
- 手把模型為自製膠囊(不從 CDN 下載 controller profile);手部模型用 three 的 `spheres` 程序模型。
- 進入 VR 的按鈕只有圖示(取代會顯示「ENTER VR」文字的 VRButton)。

## 黑板 API 細節
- `setZone` 動畫:有舊內容時先板擦掃過 0.32 秒(留下逐次淡化的擦拭痕),再逐行由左而右寫出 0.48 秒,共 0.8 秒;回傳 Promise。
- `updateValues` 累積數值,在每幀更新時以「每秒最多一次」套用,只重繪該分區 canvas,不重播動畫;粉筆顆粒以內容雜湊為種子,重繪不閃爍。
- 標記:`x^{2}`、`F_{in}`、`\frac{a}{b}`(可巢狀)、`{key}`。數字自動格式化(≥100 取整、≥10 一位小數、其餘兩位)。
- 字高:中區標題 9.5 cm、公式 8 cm、即時數值 7.5 cm;左區 5.8 cm(固定定義,自動換行);右區 6.5 cm。內容過長時自動縮小(最低 75%)。
- 另提供便利函式 `board.setAdvanced(on, content)`:開啟寫右區、關閉擦右區。

## 效能(自動化測試環境量測;Quest 3 數據**待實機確認**)
| 檔位 | draw calls(含陰影 pass) | 三角形 |
| --- | --- | --- |
| vr(無景深) | ≈124 | ≈300k |
| high(含景深) | ≈170 | ≈300k |
- 量測環境為無 GPU 的軟體繪製,FPS 數值沒有參考價值。
- 若 Quest 3 低於 72 fps,優先調整:陰影圖降到 512、`setFans(false)`、降低 `renderer.xr.setFramebufferScaleFactor`、減少窗外樹的面數。
- `vr.html` 每 5 秒在主控台輸出 `[perf]` 平均 FPS / draw call / 三角形,可用 Quest 瀏覽器的遠端除錯讀取。
