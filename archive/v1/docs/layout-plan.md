# 場景佈局方案(俯視配置)

座標約定:底座為 0.8 m × 0.8 m 正方形,原點在底座中心,+X 向右、+Z 朝向使用者(前)。
使用者站/坐在底座前方,底座前緣距離使用者約 0.15 m(底座中心在前方 0.55 m)。
桌面高度:比眼睛低 0.45 m(坐姿眼高約 1.2 m → 桌面約 0.75 m;依 local-floor 推算,進 VR 當下以頭位校正)。

## 伸手範圍驗證(所有關卡共通)

- 成人/青少年坐姿舒適伸手:前方 0.25–0.60 m、左右 ±0.45 m、桌面上方 0–0.5 m。
- 本配置所有「可抓物」(曲柄把手、旋鈕、撥桿、托盤齒輪、卷軸、銘牌)都放在
  Z ∈ [−0.05, +0.38](距使用者 0.17–0.60 m)、X ∈ [−0.38, +0.38],全部落在舒適範圍。
- 僅觀賞不操作的物件(機構後段、徽章牆、道具)可放到底座後緣(Z ≈ −0.35,距使用者 0.9 m)。

## VR 舒適檢核

- 所有可抓物 Z ≥ −0.10(距使用者 ≤ 0.65 m)、高度 0.75–1.1 m:坐姿不用起身、不用彎腰。
- 機構動件最大線速度 < 0.5 m/s(馬達轉速限 ≤ 60 rpm),無快速逼近臉部的物件。
- 無鏡頭移動;過場動畫只動機構本身。
- 微塵粒子速度 < 0.01 m/s,VR 中窗光平移幅度減半、週期 ≥ 60 s。
