# chalk-tc.woff2

- 來源字型:LXGW WenKai TC(霞鶩文楷 TC),作者 LXGW,授權 SIL Open Font License 1.1。
  取自 npm 套件 `lxgw-wenkai-tc-webfont@1.2.0`(封裝授權為 MIT,見 `LXGW-WenKai-TC-LICENSE.txt`)。
- 本檔是子集:ASCII、全形標點、希臘字母、上下標、箭頭、數學符號,加上 Big5 常用字(第一級)
  中字型實際收錄的字,共約 5400 字。子集化以 fontTools(pyftsubset)完成。
- 依 OFL 規定,子集字型不使用原保留名稱對外散布為獨立字型;此處僅作為本專案內嵌使用。
- 缺字時,`chalkWriter` 的 font-family 會退回系統中文字型。
